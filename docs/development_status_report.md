# 영월고향방앗간 개발 진행 현황 보고서

## 1. 프로젝트 개요

본 보고서는 영월고향방앗간 온라인 쇼핑몰 구축 프로젝트의 현재 개발 현황을 점검하고 실제 실행 환경에서의 동작 여부를 검증하여 정리한 종합 보고서이다. 본 조사는 코드의 변경이나 기능 추가 없이 현재 서버와 데이터베이스를 실제 실행한 상태에서 진행되었다. 

영월고향방앗간 쇼핑몰은 100% 국산 참기름, 들기름 및 특산품을 판매하기 위한 웹 서비스로, 사용자 대상 상점 기능과 주문 처리 API를 중심으로 개발이 진행되었다.

---

## 2. 시스템 구성

실제 소스코드 및 환경설정을 통해 확인된 기술 구성은 다음과 같다.

* **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+), Portone SDK V2
* **Backend**: Python 3.12, Flask Framework, PyMySQL, PyJWT, Werkzeug (Password Hashing)
* **Database**: MySQL 8.0 호환 데이터베이스 (`yeongwol_mill`)
* **External Service**: Portone PG 결제 연동 모듈 (SDK & Server Verification API)

## 7. 현재 잔여 개발 사항

현재 코드 분석 및 실행 결과를 바탕으로 확인된 잔여 개발 과제는 다음과 같다.

1. **기능 개발**: 상품 검색 기능(API 및 UI) 및 비밀번호 찾기/재설정 기능 개발
2. **외부 연동**: Portone PG 실계약 계정(MID) 및 채널키 설정 후 결제 승인 테스트 진행
3. **운영 환경 작업**: SSL 인증서 적용 및 운영 서버 DB 설정

## 8. 테스트 및 확인 결과

이번 점검 과정에서 실제 서버를 구동하고 수행한 주요 사용자 흐름 검증 결과는 다음과 같다.

* **상품 탐색 흐름 (정상 동작)**: 메인 화면 → 상품 목록 → 상품 상세 이동 및 수량 변경 정상 동작 확인
* **장바구니 및 주문 흐름 (정상 동작)**: 상품 추가 → 장바구니 수량 수정 → 주문서 정보 입력 → DB 주문 생성 정상 동작 확인
* **비회원 주문조회 흐름 (정상 동작)**: 생성된 주문번호 및 비밀번호 기반 3중 검증 조회 정상 동작 확인
* **회원 인증 흐름 (정상 동작)**: 회원가입 → 로그인 → JWT 헤더 상태 유지 및 로그아웃 정상 동작 확인
* **결제 승인 흐름 (확인 필요)**: 테스트 결제창 연동은 준비되어 있으나 실결제 테스트 환경 설정 미비로 승인 검증 미실시

## 10. 종합 현황

영월고향방앗간 온라인 쇼핑몰 프로젝트는 현재 핵심 쇼핑몰 사용자 기능(메인, 브랜드/공정 소개, 상품 목록/상세, 장바구니, 회원가입/로그인, 주문서 생성 및 비회원 주문조회)의 개발과 DB 연동이 완성되어 상점의 기본 틀과 데이터 흐름이 안정적으로 구축된 상태이다.

실제 Flask 서버와 MySQL 데이터베이스를 구동하여 점검한 결과, 상품 데이터 조회부터 주문서 작성 및 DB 저장까지의 주요 사용자 서비스 흐름이 정상 작동하는 것을 확인하였다. 전체 14개 주요 조사 항목 중 11개 기능이 동작 검증 완료(구현 진행률 84.6%, 동작 검증률 78.6%)되었다.

다만, 실제 상업 운용을 위해서는 Portone PG의 실계약 채널키 설정 및 실결제 검증, 그리고 검색 기능과 비밀번호 찾기 등 일부 보조 기능의 추가 구현과 운영 환경 구축이 마무리되어야 할 것으로 판단된다.
