# 영월고향방앗간 온라인 쇼핑몰 상용 운영 준비도 전수 점검 보고서 (Production Readiness Audit)

**점검 일자**: 2026년 8월 24일  
**대상 시스템**: 영월고향방앗간 (Yeongwol-Mill) 웹 애플리케이션 (`web_app`)

---

## 1. 개요 (Executive Summary)

현재 구현된 **영월고향방앗간 웹 애플리케이션**은 기본 쇼핑몰 UI, 회원가입/로그인(JWT), 상품 목록/상세, 비회원/회원 주문서 생성, PortOne PG 결제 연동(V2 SDK + 사후 금액 검증) 등 **핵심 트랜잭션 흐름의 시안 및 프로토타입**이 성공적으로 구축된 상태입니다.

그러나 실제 고객을 대상으로 결제를 받고 상품을 배송하는 **상용 서비스(Production Service)**로 운영하기 위해서는 **[1] 관리자 시스템, [2] 결제/배송 예외 처리, [3] 법적/행정적 필수 고시, [4] 인증/보안 강화, [5] 서버/인프라 환경** 분야에서 필수적인 기능들이 보완되어야 합니다.

## 3. 🚀 상용 오픈을 위한 단계별 실행 로드맵 (Action Plan)

### Step 1. 즉시 조치 (1주 차: 필수 법적/결제 연동)
1. **쇼핑몰 하단 푸터 사업자 정보 완성** 및 이용약관 / 개인정보 처리방침 페이지 추가
2. **PortOne Webhook 수신 API** 개발 (결제 누락 방지)
3. **다음(Kakao) 주소 검색 API** 연동

### Step 2. 핵심 운영 기능 구현 (2주 차: 관리자 & 알림)
1. **관리자 전용 대시보드 개발** (상품 CRUD, 주문 상태 변경, 운송장 번호 입력, 엑셀 다운로드)
2. **알림톡 / SMS 연동** (주문 완료 및 운송장 번호 안내)
3. **주문 취소 및 PG 환불 연동**

### Step 3. 서버 배포 & 보안 강화 (3주 차: 인프라 & 본인인증)
1. **Nginx + Gunicorn + SSL(HTTPS)** 서버 환경 구축 및 도메인 연결
2. **휴대폰 본인인증(NICE/다날)** 연동 및 비밀번호 찾기 기능 추가
3. **DB 자동 백업 및 Sentry 에러 모니터링** 설정
